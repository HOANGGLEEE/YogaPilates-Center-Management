# Yoga & Pilates design direction

The active implementation lives in `src/`. The HTML in this folder is an archived visual reference, not an application or source of live data.

Use forest green (#182521) and layered evergreen surfaces with sage (#c4d5aa), sand (#c7b899), and warm off-white (#f2eee5). Keep clear contrast for labels, keyboard focus and status messages. Error and success colors retain their meaning.

Use Yoga and Pilates studio imagery, leaf or mindful-movement icons, and calm Vietnamese copy focused on breath, posture, core strength and balance. The lotus brand mark is shared by the admin favicon and member app icons.

Reuse the existing responsive layouts and navigation. Display real packages, purchases, bookings and check-ins from the backend. Mark static schedules as illustrative and disable unsupported features. Keep API field names and stored session keys compatible.
